# 1.8.0 验收记录

日期：2026-09-25。原八组 133 项回归与新增外来 SVG 标签检查 17 项均通过，共 150 项。逐组结果及源代码哈希见 [release-1.8.json](release-1.8.json)。

真实试用保留两张已清楚的图，修复一张数组图的标题穿线，删除一张流程图中归属不清的重复说明（内容保留图注）。新工具在原 SVG 上发现导线接触，修复版有限检查通过；独立审阅核对了正常色、灰度和选定色觉模拟。旧图的不透明格子会遮住底层线，这些包围盒接触如实标待审，不冒称科学错误。

独立执行者用自拟 SVG 验证穿字返回待审、分离后通过。README 中失效的 Windows 字体路径改为从系统目录解析；另做复制包和不同工作目录试用。现有命令与示例保留。

入稿时实际发现带前缀的 SVG 根标签在当前 LibreOffice 导入链中显示空白。改用默认命名空间后，清稿和审阅稿均能显示新图；检查器对这种兼容风险返回待审。此结论针对已运行的导入链，不把有效 XML 误判为科学错误，也不声称所有导入器都存在同一问题。

工具仅覆盖明确字体、无变换文本及有限直线导线；CSS、曲线、复杂 SVG、叠层和科学含义不自动通过。入稿检查由 PaperCraft 核对 SVG 与 PNG 两种实际嵌入。技术、视觉、科学和作者确认仍分开。未测试真实 3D、全色觉条件、物理打印、新机器安装或人类理解实验。
