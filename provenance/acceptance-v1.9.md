# 1.9.0 验收记录

日期：2026-09-25。

## 产物问题与修改

前次真实稿件的两张图原样沿用，另两张主要调整局部线条和标签。执行记录支持“早期决定局部修整”，没有发现未调用技能或尝试全面重构后回退的证据。正确性修复有效，但不能算构图升级。

本轮整合设计探索与视觉解释指导：质量升级先选择核心关系做实际候选，以共同入稿尺寸比较，才决定保留、重画或回退。保留科学内容不要求保留原坐标；已有渲染工具可用不构成固定模板的理由。删去重复的探索规则，保留局部修改和仅换色的范围限制。

`compare_designs.py` 新增可选 `--placement-width-mm`。HTML 按统一 CSS 毫米宽度展示，保持各自纵横比，不随窗口缩小；记录有限字号换算，不支持的 CSS/变换保留未知。屏幕 CSS 毫米不是校准过的物理尺。旧参数和 Python 三参数调用继续工作，几何变化不自动判为更美。

## 实际生成

私人稿件选一张核心机制图，生成“追踪一个完整更新”和“两批完整地址矩阵”两种实际构图。采用前者：共享模式、两批基址、代表组的局部到全局身份和实虚分量直接相连。另一版信息更全但数字密度过高，保留作对照。入稿宽高相同，最小标签约 10 pt；已查看正常色、灰度、单一绿色觉缺陷模拟及确切 Word 渲染。未改的图不计为本轮改进。

[光学读出示例](../examples/optical-readout/README.md)来自另一个没有取得该稿件答案的执行上下文。它用装置形状、分叉路径和同一装置的两个状态组织信息，没有沿用数组或卡片布局。旧图只有文字描述，交付中的旧图是据描述重建。六个主对象、共享快门、除法前无效判断和四组构造算术均经代理核对。它支持一次迁移试用成立，不证明所有题材都能稳定生成，也不证明本次规则是收益的唯一原因。

首次示例脚本写死本机路径，复用不合格。已改为显式字体、工具、输入和输出参数；公开脚本独立复制到新目录，只带 FigureCraft，从另一个工作目录重建，9 个核心产物字节一致。对非空目录在写入前拒绝。固定作品重建不是又一次生成试用。
