# 构图探索与实际效果验收

用于要求明显改善的核心图或需要新构图的图形。保留数值、实体及关系，不必保留旧版布局。仅换色或局部修复遵守原范围，不为了流程齐全多画方案。

## 有意义的备选

先查看实际原图，定位最费力的读图步骤：找变化位置、恢复装配关系、跨区对值，还是辨认标签。先完成[对象定位](visual-explanation.md#从来源句子落实到画面对象)，再让候选改变这个步骤。两个候选需要实际回答不同的读图假设，例如“先认空间邻接再跟踪动作”和“沿动作追踪同一局部再确认归属”。两者使用同一对象、关系、必要状态和最终版面，不能让一版故意少给事实。已有对象仍像栏目拼接时，先生成整幅骨架，选择关键边界与主辅比例，再写面板及循环；数据仍保持自己的二维尺度。只修局部时检验最小有效精修；无实际缺口可保留，不为每张图凑方案。

改构图的候选应改变读者先看到什么或如何追踪同一对象；局部精修则说明具体的对比、对齐或层级改善，不冒称结构变化。依据[表示选择](visual-explanation.md)，在候选记录中写出两种不同的读取路径，例如“沿一个源的分支找到应用”和“先看重复轮廓，再读改变的原点”。若两版都仍需依次比三排数字，就没有检验这两种假设。复用图元不等于冻结旧构图。

参考图可访问时实际打开，再指出哪个轮廓、视角或共同边界组织了信息，迁移到当前科学对象；只读[五图观察](five-image-style-analysis.md)不能记成看过原图。也可查看已有公开例子的实际产物，如[支撑接触](../examples/display-support-contact/README.md)：借鉴视角如何显露接触，不搬其装置或布局。参考图的小字、面板数和颜色不决定新图的结构。

每个方案先写一句图要回答的问题和最先应看到的关系。空间图先用不含长解释的轮廓稿确定整体外形、关键接触、间隙或包含：如果它只能辨认部件名称，还不能沿边界读懂接合或隔离，就先改观察方向和剖切方式，不急着加颜色或说明。组装状态与展开状态有不同代价：前者直接显示接触和连通，后者显露被遮住的界面，但会增加恢复装配关系的负担。按照本图的主问题选择；展开图不是更高级的默认答案。

轮廓正确仍不等于关系易读。先定位读者要靠哪处差异作判断，再选视角及主辅比例。[支撑脚接触开发例](../examples/display-support-contact/README.md)固定 160×99 mm 和同一几何，比较“装配→脚槽剖面→释放空区”与“共底座四姿态→装配”。后一版虽能逐项比姿态，却把多条杆叠成扇形，容易读成多根支杆；前一版显露同一脚的开放座与释放后的真实间隙，代价是三个支撑角度转入图注，不再图内同权比较。因主问题是接触性质而选择前者；若问题改为逐项比角度，选择也须改变。局部由同一对象派生，取样点、观察方向与尺度要明确；箭头只表达来源允许的动作。保留两版及失败，不让标题或图注去否定画面中的错误连接，也不为写实感补造未知孔、支架或配合细节。

## 局部视觉完成度

先把完整图放回图注和附近正文，看主体轮廓、界面和阅读焦点。若一句大标题、多个同等粗重的面板标题、分隔线与底部结论占去主要注意力，实际出一版让主体和短对象标签领读的整幅图；有用的独立标题可保留，不把“删字”当成功。空间关系由连续边界、切面和遮挡成立，再用少量明暗表现表面。部件仍像标签框时改对象造型，不统一加斜边。整套图以同宽预览一起精修：共享文字层级、主/辅边线和角色色，让不同构图保持相同视觉分量；不能靠每图独立合格推定整套成熟。外壳修改后复查空腔与接口，精修不改科学拓扑。

调整主辅比例时，保留旧图已经清楚的身份线索。层叠对象可用局部切口显露研究层，让未变外层退为背景；实际检查转角与未切部分是否仍能说明完整堆叠，避免整层后缩被读成真实覆盖不足。互斥配置应沿用跨区域一致的身份色和备选标识，不让共享层的高亮色或箭头暗示材料转化。少量条件可共用同一指标的二维轴，直接标对象和值，但保留各自尺度和比较限制。选择时合并这些具体优势，而非整版替换后用长图注补回丢失的线索；[双床构图开发例](../examples/two-bed-composition/README.md)保留了整体/局部、运行/服务之间的实际取舍。

角色颜色不必同时充当文字色、边线色和填充色。小字可用同色相的更深文字 token，保留原来的填充和结构。改色后核对实际背景与非颜色线索；对比度通过只说明一项筛查通过，不能作为美感总分。[层板文字例](../examples/plate-labels/README.md)展示只修明暗而保留结构的实际前后产物。

## 实物比较

打开原图与实际候选，以最终入稿尺寸比较：

- 视觉焦点是否对准核心机制；第一次扫视能否发现关键区别。
- 对象和关系是否不用反复查图注就可辨；必要限定仍在图注。
- 标签是否减少解释负担；没有小字堆积、箭头交叉或装饰面造成重复计数。
- 语义颜色、轮廓和文字是否共同区分对象；灰度下仍有区别。
- 深度是否解释空间/占用，是否压过数据和文字。
- 相较原图的改善、代价和残留问题是什么。

比较前写下当前读者必须执行的操作，例如找同一对象、跨区对值、心算差值或沿分支往返；比较后指出候选消除了哪一步，是否引入新的图例、尺度或符号解释。候选各有优点时，先完成一个可检验的合并修复，再选择：

1. 指出要保留的具体图元和读图优势，如可辨的实体轮廓、紧邻分支的关系标签；将代价定位到实际对象、标签或连接段。
2. 在固定事实和版面内保留这些读图优势，不必把两版图元全部叠加。当一种优势来自局部拓扑、另一种来自完整数量时，可让一个代表结构负责前者、准确汇总负责后者；先核实完整枚举并非任务要求。需要逐项身份时仍保留全体。重排造成代价的关系，将标签绑定所属段；位置或朝向暗示未知科学几何时改表示，不能只在图注否定画面。
3. 生成并查看合并后的产物，和未改的候选同尺寸比较，记录原优势是否保留、代价是否消除及新代价。保留自然产生的失败；有明确可修问题再作一次针对性修复，无新假设不无限重画。

合并尝试仍不能解决冲突时，可以保留原图并写明具体原因；无需为了选出赢家隐藏取舍。取舍不能只问“新增理解是什么”：还要沿主要读图路径找出原版留下的歧义是否已消除、候选是否带来更严重的歧义。例如，等距存储条目与非均匀数值位置的区分，不能因原图注有一句解释就视作已解决。选择时指出实际图元与读法，不用合规项目抵消主关系的问题。已有关系通过层级与分工变得轻松可读即可构成改善，不要求扩展信息。说不出理解增量、也没有可定位的审美改善时，不称升级成功。看到评阅后生成的修订标为开发改进，不称独立验证；独立代理判断与作者认可分开，不声称已测人类阅读效率。实际合并过程见[共同参考开发记录](../examples/common-reference-demo/dev/REVIEW.md)。

## 按问题选择对照

有长解释拥挤时，先检查它是否已被画面承担。例如，两状态过滤盒沿用同一个框架，内部子对象的编号、相邻顺序和朝向也能逐一对应，“抽出后仍保持原来的排列顺序”整句可移到图注；图内保留识别对象和动作所需的短标签。若编号或排列其实变了，这句话不是冗余，而是暴露待修的图形错误。“停流后操作”“非在线状态”等条件无法由相同编号推出，不能顺手删掉。实际例子见[过滤盒](../examples/filter-cartridge/README.md)。

文字已经少而关系仍费力时，改对象对应或空间参照。固定宽高与事实，不要求每轮更少字符。给审阅者实际图与实际图注，不先解释作者意图，再让其完成事先列出的读图任务；同时记录回答依据来自图、图注还是自行推断。主关系靠图注否定画面才成立、运算映射需猜测，或删标签后只剩难解符号时，优先修复对应图元。候选若增加明显误读，即使更少字也不能抵消；可局部回退或保留旧图。

记录文字节点、词/字数、数值符号、长标签与字号分布（可用 `measure_label_load.py`），以及移到 caption/正文的内容和位置。检查解释是否只是移成巨长图注；减少的文字必须由清楚的关系或明确分工接住。数量降低仅是症状变化，核心验收是主动作更快可辨、比较没有歧义；不用自评分或虚构阅读时间代替实际产物。

以实际入稿宽度记录高度、最小有效字号和被移入图注的信息。比较过程固定版面；确需改变版式时另列为版面调整，不用它证明同等尺寸下更好读。颜色角色在一张图内必须一致；跨图复用颜色但改变意义时检查是否会造成错误联想，并提供清楚的局部标识。

## 比较工具

```text
python scripts/compare_designs.py --baseline original.svg --candidate a.svg --candidate b.svg --placement-width-mm 160 --out new-comparison
```

输入须为可解析 SVG；输出 HTML 内嵌原图和候选、提取文字及有限几何差异 JSON。它忽略颜色、ID和文字内容来比较对象几何，另比较文字位置；只能提示是否存在对象/文字几何变化，不能证明构图实质不同或更好看。没有可读原 SVG 时可用人工并排预览并记录该项未自动检查。

1.3 检查直线四个端点属性及父级变换，另列 `output_size_changed`；仅物理宽高变化报告 `OUTPUT_SIZE_CHANGED`。`use`、嵌图、CSS、裁剪等未检查的渲染特性会列在 `uninspected_features`，未知变化报告 `UNCLASSIFIED_RENDER_CHANGE`，不可称为“仅换色”。数字字符串等价（如 `10` 与 `10.0`）、引用展开、外部字体/样式和语义方向仍需实际渲染或科学审阅。所有分类继续保留效果待审状态。

[三通旋塞原创示例](../examples/rotary-selector/README.md)用两种互斥连通状态检查迁移：真实液流保留直箭头，机械转动用弧箭头，状态视图并不代表两套装置。它不沿用数表或复用分叉的布局。
