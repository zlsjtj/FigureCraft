# 不透明空间表面的可执行路径

当结构有真实空间几何、曲面与遮挡，且矢量分片出现假纹理时，可采用 `scripts/surface_renderer.py`。它由PaperCraft已实际试用的连续表面组件整理而来；当前主实现在本仓库，PaperCraft旧案例保留历史快照。它不取代二维数据图、已有矢量流程，也不自动完成构图。

```python
from surface_renderer import render
image, role_mask, lo, hi, record = render(
    faces, right, up, view,
    px_per_unit=24, scale=1,
    light=(-0.5, -0.7, 1.2), ambient=0.4,
)
```

Python依赖 NumPy 与 Pillow；模块可通过调用者显式添加已安装技能的 `scripts` 路径导入，也可连同源码复制到交付目录。用哪一份就记录哪一份哈希，不默认读取其他目录的同名文件。

`right/up/view` 是相互正交的单位向量，`view` 朝向观察者。每个面包含凸多边形 `p`（N×3）、向外法向 `n`、稳定语义 `role` 和十六进制 `color`。曲面可给 `vertex_normals`（N×3）；不要跨材料或真实折边平滑。返回透明RGBA层、可见角色掩码、投影包围盒及有限采样记录。图像按 `[lo,hi]` 放置，标签必须使用同一个投影，不能凭视觉挪到另一个表面。

逐三角形插值深度，保留每个采样点最靠前的不透明面。图形明暗仅为法向与展示光向的函数，没有透明、折射、接触阴影或物理场模拟。因此，“几何上接触”可能仍缺少可见接触线索：先选择能露出接缝的视角或精确轮廓，不能假装后端已渲染了接触阴影。

`px_per_unit` 按源几何单位计。根据最终毫米放置宽度计算真实表面dpi，不能用高dpi空画布掩盖低分辨率嵌图。标签和引线在单独矢量层绘制。SVG/PDF内嵌这层位图时称为混合文件，图面须改源码后重建；用户要求全矢量则使用矢量路线。相机、光向、尺寸和片元采样检查证明可重建范围，不证明审美完成或每像素严格正确。

把原图、完整候选和实际页面放在相同宽度看。只消除分片细纹，就按局部修复报告；构图、接触感与对象归属仍需要另行判断。
