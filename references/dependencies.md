# 依赖与兼容范围

| 能力 | 依赖 | 范围 |
|---|---|---|
| RGB、HEX、Oklab 和只换色锁定 | Python 标准库 | 不需要网络或图形服务 |
| SVG、矢量 PDF | reportlab、明确字体文件 | 按实际字符检查字形覆盖 |
| PDF 文件检查 | pypdf | 有限尺寸和文本解析 |
| PNG | Poppler pdftoppm | 显式传入实际路径 |
| 灰度、选定色觉模拟 | Pillow、numpy | 不代表全部色觉条件认证 |
| 补充 PDF 字号检查 | vendor 中的 audit_pdf_text.py | 保留 Apache-2.0，不处理全部几何变换 |
| 现有 Matplotlib 或 R 项目 | 对应运行时 | 可继续沿用；本包引擎不依赖它们 |
| 真实 3D 与通用 PDF 碰撞分析 | 另行实现和相应工具 | 不是本包已验证能力 |

`requirements-core.txt` 列测试过的 Python 包版本，安装范围由使用者选择。先运行 `probe_runtime.py`，记录自己的运行时和字体；路径存在不等于实际渲染通过。使用其他字体可能改变宽度和换行，应复验。

本包可独立安装，不要求安装 nature-skills 全仓库或 PaperCraft。宿主可调用已有科学图形技能，但目录存在不证明能力可执行。自动发现由宿主管理，安装存在不代表已验证热加载。

脚本不读取密钥或上传材料，不附字体和私人截图。渲染使用新的输出目录；字体来源、SVG 外部字体依赖与 PDF 子集嵌入分别记录。缺少依赖应报告具体未运行路径，不能仍宣称全套通过。
