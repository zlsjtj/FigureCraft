# 已有 SVG 的标签和导线

沿用原 SVG、R 或 Matplotlib 源时，不必为检查而重写成附带场景 JSON。但旧图不在场景引擎覆盖内，不能把另一个示例的 PASS 当作它的检查。

`audit_svg_labels.py` 检查有限的、无变换 SVG：匹配实际字体，计算文字墨迹边界和入稿字号，检查所有未填充直线导线，包括没有 relation 标记的辅助线和虚线。默认输出疑点，不自动移动图形。

```text
python scripts/audit_svg_labels.py existing.svg --font FONT.ttf --bold-font BOLD.ttf --placement-width-mm 160 --out label-audit.json
```

`PASS` 只说明覆盖范围内没有发现问题。曲线、CSS、变换、复杂文本、裁剪、透明和嵌入位图会进入待审。文字与线的包围盒相交标为待审：线可能被后画的背景遮挡，也可能恰好落在虚线间隙，须看实际图。不要把这些情况伪报为科学错误。工具返回码 0/1/2 分别是技术通过/明确失败/待审。

## 标签属于谁

让审阅者指出每个标题、补充说明所指的对象或分区。尤其检查冻结线、训练/测试分区、内外层和局部放大两侧的文字。标签的文字正确，但放在错误区域，仍会误导扫读。

有明确区域时，可传 `--regions regions.json`。文件包含该 SVG 的 `svg_sha256` 和 `labels`，每项指定 `text`、`owner`、`bounds: [left, top, right, bottom]`，坐标采用 viewBox 单位。区域由编辑者依据含义声明；工具只检查唯一标签是否在区域内，不替人猜归属。

## 两个常见修复

- 数组标题被列对齐虚线穿过：标题居中于它说明的整组列，在文字区域和不透明单元格内断开辅助线；保留列位置、数字和对应关系。
- 测试集说明悬在选择模块下方：移近所属区域；已有图注完整解释且图内拥挤时，可以删除重复说明，保留必要数量和边界。不靠缩小字体塞下所有文字。

修复前后用同一物理宽度查看，记录保留的内容及删去的重复内容去向。附带脚本不检查科学拓扑、实验观测完整性或美感，这些仍单独审阅。

## 入稿兼容

一次实际入稿中，合法的带前缀 SVG 根节点在当前 LibreOffice 链中出现整图空白，改用默认 SVG 命名空间后复验。检查器对此发出兼容性待审提示，不把合法 XML 判为科学错误。哈希一致不证明渲染可见；SVG、PNG 两种表示都更新后仍须看最终页。默认命名空间应为 `http://www.w3.org/2000/svg`，注册时不要把元素标签的花括号放进 URI。
