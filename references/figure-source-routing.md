# 从实际源决定图件操作

适用于已有论文或整套图精修。新建图直接读给定事实/数据，不必套此清单。

先打开旧图和论文页，找出真正影响阅读的对象、比较或小字；同时核查实际源。Word内嵌图可能比原目录的图更小，最高质量来源未必是最近导出的文件。完整保留原字节，核对身份后再选择恢复。

```text
python scripts/inspect_figure_sources.py --docx parent.docx --sources original-assets --declarations source-map.json --out new-inventory.json
```

`source-map.json`声明需人工确认的源与 drawing 对应，例如：

```json
{
  "availability_statement": "仅有原始 JPEG，未提供曲线数据",
  "drawings": [{"drawing_index": 1, "source_file": "panel-a.jpg"}]
}
```

`drawing_index` 从 1 起，按正文直属段落中的 drawing 顺序；`source_file` 相对 `--sources` 目录。先不传声明运行一次，使用输出清单定位。此清单不覆盖页眉页脚或表格内部的 drawing；脚本报告的额外表示、未覆盖部分与人工身份确认不能当作已验证。工具不按相似文件名猜匹配；有效DPI来自像素数和实际入稿毫米，不从DPI元数据得出。分别报告字节身份、解码像素身份和源分辨率关系；更多像素不自动等于同一数据。SVG含栅格图时不能称全矢量。

按操作所需证据分流：

- 数据与可编辑对象齐全：重组比较和构图，保持数据、尺度、失败及条件。
- 外部原图优于内嵌图：实际核对曲线、图例、照片/标尺、范围和身份，再原字节恢复；不放大旧像素冒充恢复。
- 只有测量位图：保留像素与测量编码，图组编排可调整，但缩小低清面板可能让整齐的布局更难读，须同尺寸比较。不能生成“相似曲线”、补照片纹理、去不利点或用描线冒称原数据。
- 图只缺图注分工：让图注解释实际颜色/形状/线型归属、尺度与示例条件。不同实验中同色可能代表材料，也可能代表扫描序次，不能未经数据允许就统改颜色含义。图注明确读图规则，不能否定画面主要关系。
- 事实足够的示意：可以重设计，选择服务关系的造型，不能因为结果曲线缺源而全部停做。

对整套图逐一记录保留、改善或源受限；不机械要求每张改，也不把全部被检查算作全部提升。完成入稿后比较实际页：恢复的源是否真被嵌入，标签是否可读，图注是否比原来更少往返。一次源文件恢复案例只证明这类处理可执行，不证明任意低清图都可提升。
