# 分层质量与完成定义

| 层 | 可执行检查 | 必须另审阅的事项 |
|---|---|---|
| 内容 | 完整声明范围内对象集合、主表示去重、占用及样式、实体/关系引用、数据计算、色改前后哈希 | 预期值来源、未标注对象、科学机制真实性、因果、适用边界 |
| 几何 | 本引擎文字度量、页面边界、文字互撞、直线关系穿字、标签槽宽、显式端点和三角箭头方向、入稿字号 | 曲线碰撞、复杂箭头、遮挡合理性、任意外来SVG/PDF碰撞 |
| 颜色 | 25对算术、可追溯派生、声明背景文字对比度、灰度/单条件CVD | 实际叠层对比、明暗层级、色觉条件以外与真实打印 |
| 文件 | SHA、SVG XML、文本节点/位图、PDF页数/毫米/搜索文本、PNG导出 | 不同编辑器对象体验、跨平台字体替代 |
| 视觉 | 实际查看最终PNG及SVG、主要图灰度/CVD、输出尺寸复核 | 作者审美认可、用户研究、期刊接收 |

状态使用 PASS / FAIL / REVIEW_REQUIRED / NOT_RUN / NOT_AUDITABLE / NOT_APPLICABLE；缺依赖不是PASS。`status`为兼容旧接口而等于`technical_status`；`overall_status`独立给出，科学或视觉未审阅就不能PASS。子项实际失败向上传播，PDF/计数子项不能在已有失败时仍报PASS。缺语义字段的旧规格可以渲染，但该项待审。未指定期刊仍为UNVERIFIED。打印/全显示器/真实D2/图像API未测试时明确列出。

机器修复顺序：改错误内容 → 调关系/端点 → 调留白/层级 → 换行或分面 → 调轮廓对比。只有最后才在可读范围内调字号。禁止靠隐藏退化、删除对照或伪造区间让图更好看。

每个交付记录输入哈希、修订哈希、运行命令、退出码、输出清单及人工观察。视觉审阅应标注是代理查看还是作者明确认可。本次验收的审阅主体为Codex代理，不是实际研究领域专家或用户。

T1–T8和A/B/C/D结果见 [验收记录](../provenance/acceptance-v1.7.md)。压力输入故意失败要记录为“正确拒绝/检出”，不能把失败文件放进成品图目录当作通过产物。科学内容未知但文件完整时仍可交付候选；不要强行给完整PASS。

当前版八组回归共 138 项，另有 SVG 标签检查 17 项，共 155 项，见[验收记录](../provenance/acceptance-v1.9.md)。构造示例的回归不替代真实稿件效果审阅，历史私人验收文件留在本地归档。

## 改善目标单独验收

通过上表表示有限检查未发现问题。用户要求视觉升级时，另按[设计探索](design-exploration.md)比较原图与候选，记录已改善／部分改善／未改善／待审。该判断需实际查看，不能由渲染脚本产生。允许交付技术合格但效果仍待改的候选，并明确说明。
