# 分层质量与完成定义

| 层 | 可执行检查 | 必须另审阅的事项 |
|---|---|---|
| 内容 | 完整声明范围内对象集合、主表示去重、占用及样式、实体/关系引用、数据计算、色改前后哈希 | 预期值来源、未标注对象、科学机制真实性、因果、适用边界 |
| 几何 | 本引擎文字度量、页面边界、文字互撞、直线关系穿字、标签槽宽、显式端点和三角箭头方向、入稿字号 | 曲线碰撞、复杂箭头、遮挡合理性、任意外来SVG/PDF碰撞 |
| 颜色 | 25对算术、可追溯派生、声明背景文字对比度、灰度/单条件CVD | 实际叠层对比、明暗层级、色觉条件以外与真实打印 |
| 文件 | SHA、SVG XML、文本节点/位图、PDF页数/毫米/搜索文本、PNG导出 | 不同编辑器对象体验、跨平台字体替代 |
| 视觉 | 实际查看最终PNG及SVG、主要图灰度/CVD、输出尺寸复核 | 作者审美认可、用户研究、期刊接收 |

状态使用 PASS / FAIL / REVIEW_REQUIRED / NOT_RUN / NOT_AUDITABLE / NOT_APPLICABLE；缺依赖不是PASS。`status`为兼容旧接口而等于`technical_status`；`overall_status`独立给出，科学或视觉未审阅就不能PASS。子项实际失败向上传播，PDF/计数子项不能在已有失败时仍报PASS。缺语义字段的旧规格可以渲染，但该项待审。未指定期刊仍为UNVERIFIED。打印/全显示器/真实D2/图像API未测试时明确列出。

机器修复顺序：改错误内容 → 调关系/端点 → 调留白/层级 → 换行或分面 → 调轮廓对比。只有最后才在可读范围内调字号。禁止靠隐藏退化、删除对照或伪造区间让图更好看。

每个交付记录输入哈希、修订哈希、运行命令、退出码、输出清单及人工观察。视觉审阅应标注是代理查看还是作者明确认可。审阅主体按本次实际执行记录，不将宿主模型的判断写成领域专家或用户认可。

T1–T8和A/B/C/D结果见 [验收记录](../provenance/acceptance-v1.7.md)。压力输入故意失败要记录为“正确拒绝/检出”，不能把失败文件放进成品图目录当作通过产物。科学内容未知但文件完整时仍可交付候选；不要强行给完整PASS。

沿用的八组回归 138 项、SVG 标签检查 17 项、文字统计边界 6 项，新增关系组件 10 项及运动/共享集成 4 项，共 175 项。以上为 1.13 历史范围，本轮增量执行与未重跑项见[验收记录](../provenance/current-validation.md)，不能借用历史通过替代本轮执行。构造示例的回归不替代真实稿件效果审阅，历史私人验收文件留在本地归档。

## 读图复述与实际修复

以最终尺寸提供图像和必要标签，审阅者先不读长图注，实际指出主体、变化和主要连接。要求指出标签属于哪一个对象/面、哪些视图是同一对象、关系的起止与方向；不能只复述标题。随后读图注和来源，区分图内直接可见、图注承接和无依据推断。已知题意的作者自审不冒称独立首读；模型观察不冒称真人实验。

审阅有歧义时由绘图执行者修回同一场景。把问题定位到实际边界、引线终点、标签归属或阅读顺序，再决定改视角、接触处、分组或文字。引线要落在可见且足够区分的目标部位；线更深只能增加可见性，不能解决端点本就无法区分的问题。小面目标密集时可调整观察方向或让终点沿同一面错开，保持物体身份和拓扑；不把所有引线挤到一个角，再用图注解释。

同尺寸比较修前修后，检查原本清楚的识别线索和关系是否仍在。若候选各有所长，实际生成合并修复后再选，不用“各有优劣”结束本可解决的问题；也不把全部图元叠在一起。源数据或几何未知时不能接受推测性评语。确认错误修后复验，纯偏好可以有理由保留。

确认问题的收尾记录指向同一作品的修后文件和检查，不能仅将问题转写为“下一步”而把原文件继续当作已修成品。核对独立图注文件只有实际图注，抽取脚本不能把“Figure 2 compares …”一类正文引用也收进去；交回论文时，选定图、图注与正文引用要在同一最终目录对应。[夹具反馈修复](../examples/fixture-feedback-repair/README.md)实际接回了引线、点遮挡和图注抽取三个已知问题，原首稿与评语仍保留。

在图文分工成立、主要关系能准确读出、画面层次与空间表达协调、没有明显阅读障碍时，可交付本次作品。技术检查不评价审美，少字或无重叠不自动通过；全维度胜过旧版、脱离图注也能说明全部实现或真实期刊认可，也不是本轮必达条件。作者认可独立记录。
