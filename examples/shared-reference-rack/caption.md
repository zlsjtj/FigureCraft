**Figure. One dilution rack supplies the identities for a shared electronic reference list.** Slots A–F contain six identical capped vials at equal liquid fill levels; their specified concentrations are 0, 1, 4, 16, 64, and 256 μM, respectively. Matching letters connect each physical slot to its entry in the single electronic list. Both independent analysis runs identify their reference concentrations by these IDs and read the same list without modifying it; the undirected connectors denote that shared reference. This static DEMO illustration specifies neither liquid volume nor physical dimensions and reports no assay measurement.

**Alternative text.** A straight rack holds six equal-fill capped vials labelled A through F. Beneath it, one electronic list pairs the same IDs with 0, 1, 4, 16, 64, and 256 μM. Two undirected branches from that single list lead to independent analysis runs 1 and 2. There is no second rack and no connector between the runs.
