# 共卷层合带 原创结构演示

DEMO：仅用于科研信息设计验证，不是制造样品、性能研究或实测结构。没有温度、浓度、流动、应力或其他场量。

同宽的三层带材按A、B、C径向顺序紧邻排列，共同绕一个中空支承管两圈。A为蓝色内层，B为浅金色中间层，C为珊瑚色外层；颜色只表示材料身份。支承管中性灰。每层示意厚度0.6，管外半径5.8、内半径4.4；第一层从半径6开始，每圈半径增加1.8，带宽沿轴向为28。以上全部是绘图单位，不是测量值；不显示尺寸轴。

绕卷结束处，三层共同沿切线延伸18，仍紧邻且保持A/B/C顺序，没有剥离或分叉。可用这个平直尾端让读者读出整体中重复的层序。若画局部，它是同一尾端/截面的放大，不是另外三层；不能加流动或展开过程箭头，因为只规定了一个静态构型。

目标：完整主图在160×95 mm、9–11 pt标签下，让读者直接看出三层共同卷绕以及卷绕处与平直尾端的连续对应。造型干净、圆润、适当留白；不要把这一空间关系拆成多个说明框。允许比较两种有实质区别的构图并选择一幅。交付可编辑几何源码、混合SVG/PDF和PNG，表面若是位图应如实标注。
