# 重复结构不必逐个画满：离子交换开发例

这是原创教学 DEMO，所有数量都是构造值。它用于检验一种表示选择：局部关系反复出现时，能否把“解释关系”和“核对全部数量”分开，而不删数据或让读者误以为多了一批对象。

原始任务在 `inputs/mechanism_brief.md`，两份 CSV 保存完整区域和系统数量。任务要求准确表达这些数量关系，没有要求把 80 个位点逐个画出。若任务要求检查每个位点的身份、相邻关系或异常位置，本例的汇总方式就不适用。

## 两种实际候选

| 候选 | 读图顺序与收益 | 代价及选择 |
|---|---|---|
| [exchange-led](exchange-led/figure.svg) | 先看同一对位点由两个 Na⁺ 占用变为一个 Ca²⁺ 桥接；再沿区域引线读完整数量表 | 表格保留准确值，但不能像比例条一样立即比较占用份额。采用此版，因为本任务首先需要说明共享位点和二对一交换，空间对应也更直接。 |
| [region-led](region-led/figure.svg) | 先看一个浴液中的三层珠体与精确占用条；下方代表结构解释二对一交换 | 比例条编码的是位点而非离子，读者须结合数字辨别；层与行只靠名称对应，机制处在次级位置。作为替代候选保留，不标成失败或赢家。 |

两版均为 160 × 124 mm，最小文字 8.5 pt，主标题 12 pt、主要栏目标记约 10 pt。重复的局部前后结构只代表同一对位点，不追加到数量表。固定数表负责完整数量，局部结构负责结合关系。没有把两版所有图元叠加在一起；选定版保留了明确的双位点拓扑、紧凑区域对应和可查的全部数字。

![选定成图](exchange-led/figure.png)

这种取舍借鉴参考图中“整体加局部解释”的组织方式，不复制领域对象，也不要求所有机制图都用此布局。此处保留二维径向截面，使给定的径向边界更明确；未使用装饰性透视，不声称本例检验了立体造型能力。

## 从源码重建

需要 Python、reportlab、Pillow、numpy、pypdf 与 Poppler。字体和原生工具路径显式传入，不打包系统字体。可从任意工作目录运行，输出目录必须不存在。

```text
python build_exchange.py --inputs inputs --out NEW_OUTPUT --font FONT.ttf --bold BOLD.ttf --pdftoppm PDFTOPPM
```

默认重新生成两版 SVG、矢量 PDF、PNG、灰度、单条件近似色觉模拟、图注、替代文本及核对记录。`--candidate exchange-led` 或 `--candidate region-led` 可只生成一版。SVG 为独立可编辑图元和文字；PDF 嵌入字体子集，SVG 在其他机器仍依赖指定字体。该脚本是固定教学例的重建器，不是任意数据的自动布局器；换了数据必须重新设计，约束不符会拒绝运行。

## 这次实际核对的范围

- 两种布局从本源码生成；选定版的正常色、灰度及近似 deuteranopia 已由模型查看。两种布局正常色都查看过。
- 源 CSV 守恒、每区 `2 × Ca + Na = 位点数`、所有前后总量、PDF 毫米尺寸、真实字号和缺字检查已执行。
- 图内保留所有区域的 Ca、Na、位点数量；图注保留半径、浴液前后数量、瞬态与模型边界。源文件继续保存全部数值。
- 首次 region-led 的末行说明接触图形，已调整；原始失败记录在本地开发归档保留。没有拿这个修复当成独立质量验证。
- 此例经过开发调优，不能当作新材料上的盲测。真实读者、作者审美认可、打印、跨编辑器和所有色觉条件均未验证。

可见改善是：二对一关系由一处足够大的拓扑直接表达，不再要求读者检查 80 个微小位点；区域数量仍可逐项核对。代价是少了全体位点的逐个展开。是否在陌生任务中仍能作出合适选择，需要另用未调优材料验证。
