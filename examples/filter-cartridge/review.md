# 分层复核与阶段边界

**技术。** 最终文件的 XML、图元集、哈希、单页矢量 PDF、可搜索字体文本、300 dpi PNG、尺寸和有限几何检查通过。全文字至少 9.07 pt，未缩字号删说明。`geometry_audit.json` 从真实 SVG 读取矩形位置，核对固定外壳、接口和圈不变，以及框架和两层同一平移、层序与包含关系不变。机器检查不等于装置实验。

**科学/机制。** 同一生成模型按原始任务描述核对：工作状态两层在进出口之间；两层和框架作为盒体沿侧面直线移出；外壳、接口和圈留在原位置；流动在更换前停止。两条关系现在均为 `motion`，并各自从同一移动对象指向其新姿态，完整端点/三角箭头声明保留。未给流量、材料化学效应、时间或可靠性暗示。模型结果仍是任务报告，原始模型和日志未独立复现。

**模型视觉。** 已实际查看最终彩色、灰度和 Machado 单条件色觉模拟。相比 round2，底部整行解释和两个重复补语退出画面，候选阅读可沿“就位盒体—同编号抽出盒体—Cartridge”完成。固定密封圈标签仍保留，因为光靠轮廓难以识别它的作用。编号与位置在灰度下可辨，未发现裁切或碰字。此为知道任务和编辑理由的同一代理判断，不能称盲读、真人理解实验或作者审美接受。

| 阶段 | 实际行为 | 可据此判断什么 |
|---|---|---|
| round1 | 原 motion 词汇不受引擎支持，导出拒绝并保留失败 | 原工具枚举不覆盖机械动作 |
| round2 | 在全新上下文产生 A/B 实图与英文稿；用 dependency 兼容字段 | 初稿关系可读，但仍有图内冗余；不是最终视觉成功 |
| round3 | 收到主代理反馈后，移走已由图形表达的说明，保留必要对象/状态 | 属于反馈后的标注精修，不是首次独立能力 |
| round4 | 引擎维护者增加 motion 后，恢复原生语义，重建并复核 | 最终 motion 输出可用；不能把维护者回归测试算成本代理测试 |

round4 第一份内部导出保留了旧兼容语义中的 `ref-pipes → ref-housing`；科学核对发现这不是同一对象的运动，于 `round4-motion-final` 改为 `ref-housing → ref-housing`，并记录随动的两个接口。候选运动为 `frame → frame`，随动集合为 frame/layer1/layer2。图形本身没有改变，原内部导出保留；最终 `final` 复制自修正后的产物。此例也说明枚举合法与箭头几何 PASS 不自动证明关系身份正确。

本代理实际复用的通用组件是 `scene_components.declare_count`（一项函数，九类实体调用）；几何通过原生 rect/line/polygon/text 构造。没有新增领域组件。`layered_slab`、`array_grid`、`sampled_pattern`、`branch_bus`、包覆颗粒组件经比较不适合这里的包含与侧抽关系，未强用。实际执行工具包括运行时探测、引擎渲染/有限检查、PDF 字号审计、构图对比及本例 SVG 坐标复核。

未验证：实物尺寸和间隙、密封圈截面、带压安全、流体仿真、泄漏、过滤效率、寿命、力、替换时长、加工装配、打印和全部色觉条件。作者确认：待确认。技术记录、模型机制判断、模型视觉判断和作者接受分别保留。
