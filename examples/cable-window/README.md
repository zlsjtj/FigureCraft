## 重建

在 FigureCraft 根目录执行，所有外部依赖由使用者显式提供，输出须为新目录：

```text
python examples/cable-window/build_cable_demo.py --skill-root . --brief examples/cable-window/brief.json --font FONT.ttf --pdftoppm PDFTOPPM --out NEW_OUTPUT
```

需要 requirements-core.txt 中的 Python 库、字体和 Poppler。脚本生成两份可编辑场景 JSON，再调用本包渲染器。子命令失败会令主脚本返回非零退出码；本例已执行正常重建、异目录重建和受控失败检查。异路径下 SVG 来源摘要可变，已比较可见 SVG 树、PDF 和 PNG，不能要求来源路径变化后全部文件逐字节相同。
