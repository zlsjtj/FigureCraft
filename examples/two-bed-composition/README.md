# 双床机构：完整对照与主体加局部的取舍

这是构造DEMO，所有材料、观察和数值均不是实测科研结果。它来自已知案例的定向开发，不能冒称陌生任务首测。所选图为160×100 mm；[实际尺寸图](selected/figure-96dpi.png)、[可编辑SVG](selected/figure.svg)、[PDF](selected/figure.pdf)和[确切图注](selected/caption.txt)均在此目录。

旧图完整并排展示两种运行状态，公平比较容易，但重复外壳、质量标注和密集纹理使三个视图争夺注意。第一轮实际比较了以运行态为主、以维护态为主的两个构图。选定稿让S运行态承担主体，R保留有完整起止的壁侧旁路，右侧用同一空托盘的浅视图说明取出状态。没有新增拒绝配合几何，定量结果没有透视。

得到的是密封作用与维护状态的清楚主次；失去的是R完整外壳和主路的同屏逐项比较。辅助截面必须保留路径两端及对象身份，否则裁小只会遮住关系。图注承接非对称接口与未知形状，不靠它否定画面。详见[选择记录](选择记录.md)与[非生成者模型复阅](模型复阅.md)。复阅确认局部改善，也保留旧图更直接之处；没有真人审美认可。

## 文件与重建

- `before/`：上一轮实际图，不由本轮源码重建。
- `first/`：第一次两种候选及对应初版脚本；重建首稿用这里的build.py。
- `source/build.py`、`source/selected.json`：最终源码与参数。
- `selected/`：最终SVG/PDF/PNG、灰度与deuteranomaly100、标注与来源。
- `data/`：固定任务、草稿、事实和演示数据。这个示例只重新绘制机制图1；图2与数据的全稿保留检查在本地实际交付中，不声称这个目录重绘了定量图。

依赖为Python、ReportLab、NumPy、Poppler的pdftoppm，以及用户有权使用的Arial普通/粗体TTF；字体不随包分发。渲染器可以替换字体，但需重新看字号与换行，哈希一致性仅针对记录过的运行时。

```text
python source/build.py --params source/selected.json --out new-output --font /path/to/arial.ttf --bold-font /path/to/arialbd.ttf --pdftoppm /path/to/pdftoppm
```

从不同工作目录运行时将上述路径写全。输出必须为空或新目录。已在复制后的独立目录重建，10个图形导出哈希一致，见[固定源记录](固定源重建记录.json)。这证明源码可重建，不等于技能在新材料上能自动获得同样效果。

该案例帮助选择表示范围，不规定所有图都要大主体、三视图、浅透视或这种配色。若任务需要完整状态逐项比较，应保留完整视图。
