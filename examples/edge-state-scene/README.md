# 对象与状态先落到场景：FigureCraft 开发案例

本例使用已有的四 patch 扩散教学 **DEMO**。它是知道上轮评语后的开发，不是未知材料试验、实测结果或真人审美认可。输入见 `input/notes.md`，本例只画其中的 W1→W0 入站接口，不使用构造的性能表。

最终选择：`output/selected/figure.svg`、`figure.pdf`、`figure.png`。PDF 为 **160 × 100 mm**；主要标签 9.5–11 pt，辅助拓扑及 DEMO 标识 8.5 pt。SVG 中对象和文字独立可编辑；PDF 保留文本，PNG 由 PDF 渲染。它是二维逻辑场景；源材料没有物理装置或三维几何，未为“空间感”添加虚构厚度。

## 先作出的对象选择

| 来源给出的关系 | 图中如何承担 | 为什么不能只留规则框 |
|---|---|---|
| W1 已发送 17，正在准备 18 | W1 网格的源边；实线 `copy 17`；另有通向 free 槽的 `write 18 when ready` | 相邻的“准备 18”不能成为所有箭头的默认时间 |
| 两槽存值、epoch、step、ready | 两个可数槽；READY 槽内有缩小的同形值条和 `(e, 17)` | 槽是容器，条带是副本；只写 READY 看不出复制了什么 |
| W0 ghost 为邻居值副本，供边界更新 | ghost 独立条带邻接边界格，短箭头进入边界 | ghost 不是额外物理格，也不能被“boundary update”大框吞掉 |
| 匹配与释放是两件事 | 实线 match 到 ghost；虚线 release 返回已占用槽 | 释放不能返回 free 槽；“标签正确”不自动保证仍活跃的值未被覆写 |

网格划线只帮助识别场和边，不编码具体网格尺寸；本图只展开一条接口。W0 仍需全部适用邻居，四邻接小图保留 W0/W1/W2/W3 的位置且不增加对角交换。

## 两条阅读路径与最终取舍

| 实际图 | 优点 | 代价及处理 |
|---|---|---|
| A：先认邻接场，再追踪接口 | W0 左、W1 右与拓扑一致；源边和 ghost 都有空间位置 | 两槽悬在两场之间，归属仍靠名称推断；copy/match 挤在短连线上方 |
| B：先沿值的旅程，再认使用者 | 主链一行可追踪，重复规则文字少 | W1 被放到左侧，源边图形也面向右；易把数据阅读顺序误认为真实边方位。槽也没有明确归入 W0 |
| 选择稿：归属场景 + 连续主链 | 将两槽、ghost、边界放进同一 W0 存储组；恢复 W0 左/W1 右，主链右→左；时间限定紧贴动作 | 右→左阅读不是所有读者的习惯；但与本材料拓扑一致。完整 grid 尺寸、其余接口和超时策略由输入/正文承接 |

这次合并没有将全部候选图元叠在一起。它保留 B 的紧凑值链和 A 的对象位置，并用一个有含义的所属边界解决槽的归属。主标题、拓扑和两槽满时等待的规则均处于次级位置。没有把图注当作修补错误方向的手段。

`retained/first-merge/` 保留实际失效合并稿及 scene 源：虽然归属框已加上，W1 仍在左侧；READY 字色的浅底对比也只有 4.27:1，低于技能内部筛查线。最终修复将主场景恢复为来源拓扑方向，并只加深 READY 文字色。对比度修复是技术修复，构图改善来自对象归属和方向安排。

## 图注与替代文本

**图注。** 单个入站接口的受保护边值复制（构造 DEMO）。W1 已发送 step 17，正在准备 step 18。图从右向左追踪已发送的边值、副本所在 READY 槽、W0 ghost 以及 boundary update 17；`e` 表示 partition epoch，只有 epoch 和 step 同时匹配的槽可供该次更新使用。虚线释放返回已消费的槽，下一次写入在准备好后进入 free 槽。迟到 `(e,16)` 不匹配本次更新；两槽仍活跃时 W1 等待。浅色大框只表示 W0 本地存储归属，不是物理地址或硬件外形。网格标记为代表性示意，只展开相关 ghost 边；小图保留四条边邻接。没有规定所有旧包何时丢弃，也没有暗示无限重叠或最优槽数。

**替代文本。** 右侧 W1 的高亮源边经 copy 17 到左侧 W0 所属 READY 槽；槽内同形副本通过 match 到 ghost 条，再供边界 17 使用。释放虚线返回该 READY 槽。W1 准备 18 的虚线进入另一个 free 槽。下方保留不匹配 16、两槽活跃须等待和四 patch 邻接。

## 重建与查看

运行环境：Python 3，`reportlab`、`pypdf`、`Pillow`、`numpy`，Arial 常规/粗体及 Poppler。依赖和字体由调用者显式提供；不需要 Matplotlib。

```text
python source/build.py --out NEW_OUTPUT --font Arial.ttf --bold-font Arialbd.ttf --pdftoppm pdftoppm
```

从任意工作目录运行均可；输出目录必须不存在。命令生成 A、B、选择稿及 96 dpi/200 dpi、灰度和单条件色觉模拟。`source/drawing_backend.py` 是上轮 DEMO 的普通 SVG/PDF 后端，本次构图在 `source/build.py` 中；输入科学内容没有来自参考图片。

实际比较请看 `comparison.pdf`，其三页分别是同宽 A/B/选择稿；也可直接打开各 SVG。`checks/` 保存字号/标签/哈希记录。文字线段筛查对网格背后的白色标签遮罩报告待审；已看实际 PDF/浏览器 SVG，六处疑点均为白色矩形后绘制遮住网格，实际没有穿字。保留机器原状态，不将代理查看改写成自动 PASS。

正常色、灰度与色觉模拟已由开发代理查看；PDF 与浏览器 SVG 已按约 605 px 的 96 dpi 页面查看。屏幕 CSS 毫米不保证设备实尺，未做打印、人类读时、作者接受或全部编辑器兼容性试验。两个候选与修复后的成品证明本次开发过程已执行，不证明未知题材的泛化效果。
