# Implementation and acquisition notes (DEMO)

- Each tile has two acquired 96×96 pixel planes A and B from the same stage position, after the instrument's supplied chromatic-offset correction. Two channels have different stain intensity, so pixel intensities cannot be compared as if they were the same feature map.
- Existing library phase correlation returns a 2D translation and a quality score. This library, acquisition, stage-grid initialization, bilinear resampling and overlap blending are inherited. No new estimator or interpolation algorithm was written.
- Baseline Stage uses the recorded stage-grid translation for both planes. Baseline Independent calls phase correlation separately on each plane's tile against the respective already-positioned overlap.
- MosaicPair obtains translation from A once per tile when A's existing library score is at least 0.8; otherwise it uses that tile's stage-grid translation. The threshold was copied from the acquisition workflow and fixed before these records. There is no threshold sweep or learned selector.
- The selected translation vector is stored under a tile ID. Both A and B lookup that same immutable record. They are separately resampled into two output mosaics. Masks are transformed with the same record to keep paired valid regions. The implementation checks identical ID sets before export and refuses missing pairs instead of silently filling one channel. This check does not detect physical channel misregistration.
- Each tile is processed as a pair; the log stores source of translation, score and tile ID. A failed A score does not trigger independent B registration. This avoids introducing two placement choices for the pair. It can still give a globally misplaced pair if stage metadata are wrong.
- Translation-only correction is assumed. Rotation, specimen deformation and channel-specific chromatic shifts are outside this implementation. An injected residual B-only shift of (2,-1) pixels appears in the third group to test this boundary, not to tune a fix. No later alignment pass is performed.
- Six synthetic mosaics per group, each 16 paired tiles. The same images and fixed settings were used across methods. Pair residual is the median distance, in pixels, between known paired fiducials in the two output mosaics after placement. Mosaic placement error is median tile displacement versus the synthetic ground truth. These are two different quantities; an internally consistent pair can still be at a wrong global location. Runtime is median seconds per mosaic on a single demonstration CPU configuration, including registration and resampling; no cross-hardware inference.
- In the weak-B group 5 of the 96 A tiles fail the score gate; in the sparse-both group 37 fail. Rejections apply once per pair. Residual values include all tiles, including fallbacks. No examples are dropped. No claim about future images is established.
- Optional schematic coordinates, if a concrete example helps: tile T5 has A and B local bounding box [0,96]×[0,96]. Selected translation is (84,3), used for both output planes; a local fiducial (10,18) maps to (94,21) in each. A B-only residual optical shift would remain after this shared placement. Coordinates are illustrations and are not additional observations.
