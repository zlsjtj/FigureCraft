# Git 空白检查的实际结果

两个仓库完整 `git diff --check` 均返回 1。提示位于本轮冻结前已有改动中的版本字段、候选验证页和两处参考文字，行尾为 CRLF。仓库 `.gitattributes` 使用 `* -text` 保留源字节，没有要求转换这些行尾。

这些文件与本轮冻结副本哈希一致，见 integrity.json；本轮没有为了获得绿色结果改写历史证据或做行尾清理。本轮修改的已跟踪 `docs/examples.md` 单独执行 `git diff --check` 均返回 0。新增案例已实际执行重建并检查引用，但不能把这项记录表述为整个未提交工作树的默认空白检查全部通过。
