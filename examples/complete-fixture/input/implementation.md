# 原创验证材料 仅为 DEMO

不存在真实实验、测量客户或已发表装置。以下记录和表格是为技能评估固定的合成输入，不允许写成真实研究结果。没有外部参考文献，也不提出首创权。

装置记录：三个互相隔离的样品腔分别为 S1、S2、S3。每个压力传感器测量本腔样品压力与下方同一个参考腔之间的差。参考腔沿底座横贯三个传感器；它是三个传感器参考端所面对的同一连通空间。样品腔彼此不连通，也不与参考腔连通。隔膜分开样品侧和参考侧；本示意没有给出传感器机械尺寸、隔膜挠度、流量或流动方向。图可作明确的非比例示意，不得画出穿过隔膜的流动箭头。

前一装配方式同样使用共同参考压力、相同传感器和隔膜，只是三个参考端各自通过独立软管连接到参考源。新装配用一个可拆换的参考底座替代这三段软管。底座上表面有三个密封座，拆装时三个样品模块位置不变；底座由两根定位销对正，单片密封垫同时围住三个参考口。开盖前必须先卸压。软件差分与传感器量程不变。

记录 A：把底座分成三个不连通参考盒的备用设计没有制造，没有测试，不属于结果。记录 B：共享参考本身并不是新功能，软管式基线也有。记录 C：省去定位销的控制件仍能装上，但三次装配中两次在泄漏检查中失败；其 setup time 只代表尝试时间，不能当作可用速度收益。记录 D：工况切换后的60秒稳定段被排除；同样时间窗用于旧/新装配。表中 cycle 是合成配对条件，非随机抽样；只允许直接描述这三个条件，不能计算总体显著性或声称批量制造可靠。

诊断：隔膜到参考腔的关系应可从图形读出；这不是三条传感器数据流。只给两个布局约束：三个样品腔沿一行，参考底座在其下方。横向距离和尺寸都未规定，可为示意取合理间距但不得据图读定量尺寸。原占位图是一份部件清单，无法看出物理分隔。
