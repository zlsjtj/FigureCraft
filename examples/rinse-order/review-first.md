# 独立模型辅助首读记录

本阶段只读 `review-packets/fresh-front/R.png` 与 `R.md`。先看图，再读前部。未读任务原始材料、技能、历史、其他产物或版本记录；以下不判断尚未提供来源的科学真伪，也不将模型辅助首读称为人工测试。

图像读取为 1890 × 1182 px，元数据约 300 dpi，对应 160.02 × 100.08 mm。以下以 160 mm 成图宽度为尺度评估，不把工具展示的放大像素尺寸当作出版阅读尺寸；本次没有实体屏幕尺校准或真人阅读测试。

## 1. 先看图能恢复的信息

### 对象与连接

- 左上 Sample 和左下 Rinse 是两个液源，分别从上、下进入 V1。V1 的唯一右侧出口进入 Pump。
- Pump 的右侧线路进入 V2，箭头一致向右。图中央的 `Feed segment / 2.0 mL nominal` 最直接地归属于泵到 V2 之间这段水平线路。
- V2 的上支路先向上、再向右，经过标作 Seat sensor 的小方框后进入 Holder，随后从 Holder 右侧绕向 Waste 上口。
- V2 的下支路向下、再向右，直接进入 Waste 左侧。`Bypass` 归属于该下支路，`Through holder` 归属于上支路。
- 图展示的是单个 Holder、单个 Pump、两个选择阀和共用废液容器。箭头允许恢复流向，没有明显交叉线连接歧义。
- 上方 `CONSTRUCTED DEMO` 与 `Topology only` 明确提示这是构造演示及拓扑图。图本身没有给出膜片、密封件、流量计或称重部件的结构信息。

### 阀门选择与顺序

- V1 的含义可以由两进一出推得：在 Sample 与 Rinse 之间选择。V2 在经过 Holder 和直接 Bypass 之间选择。两个阀内都没有画当前选通状态，因此上半图应读作可用路线，不应读作两个入口或出口同时开放。
- 下半图的 `V1: Rinse throughout` 应同时覆盖 P、Q 两行冲洗步骤。
- P：V1 选择 Rinse；V2 先走 Bypass，累计 4.0 mL；再切到 Holder，累计 8.0 mL；之后进入 Sample。`Then sample` 说明 P 的后续动作，但图没有直接写出后续采样的两个阀状态。我会推断 V1 改选 Sample、V2 维持 Holder；该推断不等于图中显式说明。
- Q：V1 同样保持 Rinse；V2 先经过 Holder 8.0 mL，再走 Bypass 4.0 mL。右侧将 Q 指定为 Diagnostic control。图没有说明 Q 冲洗后是否采样，或若采样如何把 V2 从 Bypass 切回 Holder。
- P、Q 均为 12.0 mL，两块颜色和数值一一交换，能很快看出比较的是顺序。图中没有时间数值，不能仅凭图判断 P/Q 用时相同。

### 标签归属、误读风险与视觉负担

1. **Feed segment / 2.0 mL nominal，图中央泵与 V2 上方。** 最近的对象是 Pump→V2 水平段，但没有起止标记或引线，无法确认 2.0 mL 是否只包含这段管路，还是也包含泵腔、V1→Pump 段或 V2 内部。首读只能恢复“名义供液段体积”，不能恢复精确计量边界。
2. **Seat sensor，小方框位于 Holder 左侧的液路线中。** 引线明确指向方框，标签归属不模糊；但方框截断流体线，容易被读成串联在液路内的传感器或节流件。仅凭图不能确认它检测 Holder 就位，还是检测该处流体状态。名字中的 Seat 提供线索，却未完全消除符号语义负担。
3. **Then sample 与 Diagnostic control，P/Q 右侧。** P 的终点动作明确、Q 的终点是角色名，二者信息类型不同。读者可能误以为 Q 不进入取样检测，因此无法直观理解它如何提供可比的诊断结果。这是图中未说明的后续流程，不是已经证实的实验缺陷。
4. **V1/V2 两个圆形阀。** 连线支持“选择阀”的解释，但单看图未显式标注三通选择或互斥选通。对熟悉液路的人负担很小；对普通读者，上下支路同时可见可能短暂引起分流或混流的联想。下半顺序图能帮助纠正 V2 的分流联想。
5. **160 mm 成图阅读。** 主体标签和各体积数字明显分层，泵、阀、容器可辨，路线间距充足；下半 P/Q 对照不依赖小字号说明。最小一层是顶栏提示、Seat sensor 与 V1 状态提示，按该图像比例估算仍约为 9 pt 量级。主要负担是上述语义边界，而非文字拥挤。未进行可达性量测，不能据此宣布所有用户或打印条件下都已验证可读。

## 2. 再读前部后恢复的论文主张

### 关键改变

这份 DEMO 改的是冲洗程序的先后顺序：先让液体绕过可复用的 Holder 排向 Waste，再冲洗 Holder。硬件沿用既有部件，不声称发明新的泵、选择阀、Holder、旁路操作或冲洗操作。前部将贡献落在“明确这一个有顺序的组合，并用相同冲洗量的逆序比较检验顺序作用”，没有提供文献优先权主张。

位置依据：标题；摘要（R.md 第 7 行）；引言第 2 段（第 13 行）。

### 主要证据及比较逻辑

- 构造的水相序列 A、B 中，所提顺序以每周期 12.0 mL、43 s 达到预先固定的 0.50% carryover 阈值。
- 交换相同的两段体积，并保持相同总时长，结果不达阈值。这个比较比单纯少用液体更能对应“次序可能重要”的主张。
- 经过 Holder 的参考方案也达阈值，但需要 36.0 mL、112 s，所以利益是给定条件下的用液量和用时降低，而不是所有其他方案失效。
- 更持久残留的序列 C 中，所提方案失败。这个反例限制外推范围。
- 另有一个 acknowledgement fault，用来说明采样许可需要依据已确认的阀状态。前部将它称为独立演示，没有把它当作冲洗机理的证据。

以上均是摘要第 7 行所述的供给示例记录。前部未给出实际 carryover 数值、阈值余量、A/B/C 的具体组成、重复次数以外的统计细节或故障轨迹，当前无法核验结果。

### 适用边界

- 材料开头明确 `Constructed DEMO`，所有记录是提供的说明性样例，不是实验、产品主张或可发表研究结果（第 3 行）。
- 有利结论只覆盖给定 A、B，C 已直接失败，不能主张一般性降低冲洗需求（第 7 行）。
- 单次构造记录不能建立实体清洗机制或真实仪器性能（第 7 行）。
- 既有硬件和传统操作不构成新的硬件贡献；没有文献或优先权主张（第 13 行）。

这些边界在标题、开头、摘要、引言重复出现，但各自分别限定演示性质、实验推广性和创新范围，当前没有读出相互冲突。

## 3. 前部阅读负担与待全文核对的问题

1. **摘要第 7 行：A/B/C 首次出现未给简短对象含义。** 首读记住了“两种通过、一种失败”，但尚不知道序列代表不同污染物、运行历史还是液体性质。读者需要暂存三个字母，等待方法部分。这不妨碍理解总体比较，却延迟了对适用范围的具体认识。
2. **图中 P/Q 与摘要中的 proposed/reversed 没有显式同名对应。** 顺序足以把 P 认作所提方法、Q 认作逆序控制，但目前需读者自行完成映射；A/B/C 又是一组不同维度的字母，增加少量工作记忆负担。
3. **摘要末半段加入阀确认故障，主题由冲洗效果转为采样许可。** 独立性已用 separately 提示，但前部尚未说明这条控制可靠性线如何与主比较共享验收条件。它有实际意义，不过需要在后文看到故障如何被判定，以及“位置已确认”与“化学清洗达标”各由什么证据证明。
4. **引言第 11 行：completed command 与 successful cleaning 连在一起。** 读者可能把阀确认误读成清洁确认。当前我将它理解为提醒“程序执行完不等于清洁达标”，而不是说座位传感器或阀反馈能够证明 carryover 达标；需全文验证两类判定是否始终分开。
5. **引言第 13 行的硬件清单。** flat porous disc、two seals、flow-meter integration、gravimetric collection 不在拓扑图中出现。清单有助于限定未改变的硬件，但首读无法把这些词逐一定位到图上。因为图已标 Topology only，这不是已证实的漏画错误；读者仍需后文得到测量与体积计算的具体定义。
6. **目前的积极点。** 标题直接给出顺序、共同 Holder、节液与边界；摘要把固定阈值、同量逆序、较耗液参考和失败条件放在同一段，比较关系容易复述。引言第二段清楚区分传统部件与程序改动，没有把熟悉的器件堆叠当成创新。

## 4. 本阶段结论

从限定的两份材料能够恢复主液路、两阀的选择角色、P/Q 顺序差异，以及“有条件节液节时、逆序失败、持久残留条件失败”的论证结构。最需要原始材料与全文消除的不确定性是：名义 2.0 mL 的准确边界、Seat sensor 的实际检测对象、Q 结束后的检测/取样状态，以及阀状态确认与清洗达标的分离。此处是独立模型辅助首读，未作真实性核验，也未作作者验收。
