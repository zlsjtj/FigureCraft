## Rough manuscript text

We use conventional selector valves and a pump in a liquid analysis instrument. The controller counts delivered volume, handles modes, waits for valve acknowledgement, and checks the holder-seat sensor. The holder uses one porous disc and two seals. The control program contains sampling and cleaning. There are conventional flushing steps. The device was evaluated with different protocols and sequence labels. Time, volume, and carryover were recorded. The system can save rinse volume in some comparisons, while the sequence with persistent residual needs attention. A missing acknowledgement was also investigated. The current evidence has only constructed single-run records and cannot establish a physical washing mechanism. The implementation was finished and all these records are retained.
