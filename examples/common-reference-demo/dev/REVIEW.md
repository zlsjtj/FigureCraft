# 从候选取舍到完成成图

这个公开教学例在两张已有候选之后继续开发，不是独立盲测。固定事实仍在 [输入](../input/figure-task.md)。

旧候选的标签靠近关系，新候选的镜头与支架便于认出相机；新版也把残差标签放得较远，相向镜头容易让读者猜测未给出的真实光路。本轮保留造型，改用正视相机符号和无向观察折线，使物体位置主要表达逻辑分组。各相机与自己的写入箭头、记录形成同一行，标签随关系段定位。

同一源码比较过横向独立行和纵向两列。选 [独立行成图](attempt-01/rows/figure.png)：C1到L1、C2到L2可分别平顺追踪，观察折线不冒充光线；两列方案下方输出空间较紧。初次产物和完整开发日志留在本地交付，没有删除失败来证明胜出。

宽高160×90mm，必要最小字号约10.08pt；色彩只区分观察与写入及对象角色。词数比两张旧图有所增加，新增的“Write”让箭头含义就近可读；因此本例不是减字成功的证据。开发者实际查看了正常色、灰度和选定色觉模拟。尚不代表真人认可、真实光学布置或独立迁移验证。

[SVG](attempt-01/rows/figure.svg)、[PDF](attempt-01/rows/figure.pdf)、[源规格](attempt-01/rows.json)、[重建脚本](build.py)均可查看。该脚本实际调用 relation_path，不靠图注修补默认箭头。

从仓库根目录运行（输出新目录）：

```powershell
python examples/common-reference-demo/dev/build.py --out new-camera-build --font $figureFont --pdftoppm $figureRaster
```

脚本会生成两种构图，采用rows。可用 --skill-dir 与 --input 显式传路径从新工作目录运行。正视相机、棋盘左置只是本题决定；通用技能只保留标签归属、位置是否误导和候选优点合并的方法。
