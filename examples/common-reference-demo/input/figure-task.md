# 固定输入：共同标定板与独立记录

这是原创结构教学图，不是实验结果。绘图目标：让读者区分“共用一个参考对象”和“各自的数据输出”。

两台固定相机 C1、C2 都观察同一块被动棋盘标定板 Board。只有一块板。板不会发送数字信号。每台相机独立计算自己观察到的角点残差，并把它写入对应的记录 L1、L2。没有相机间通信，两个记录不合并。不要把视线画成板向相机发送数据的箭头。不给焦距、距离、角度或性能数值。图形位置是示意，不是光学校准设计；不要发明透镜参数或立体重建功能。

交付一张160mm宽、最高100mm的英文机制图，SVG可编辑、PDF矢量、PNG300dpi；独立源码或场景JSON和重建命令。主标签约10pt，最小不低于8pt。允许克制2.5D表达相机/板的对象区别，定量尺度不适用。不要把所有对象画成同一种说明卡片。关键关系让图形承担，图注交代必要条件。只交一个主要候选，保留自然产生的失败，不反复挑选最好一次。
