# 首稿模型自审与唯一一次修订

先查看 first/figure.png，再检查同一产物的灰度和单条件色觉预览，随后读取实际SVG/PDF审计。首稿图片 SHA256：8301c0c808eea9677cf566cf15da7f5d7c8512fecedf4300bd804238f9526c88。

成立的部分：完整主物体比旧 control 更有视觉主次；辅助图保持完整白色径向间隙；开口引线位于 r=10.5、theta=0 的无材料角区，周围四个PNG采样点均为白色，恢复名称而不把有色内壁称为空区。同轴辅助图与主图使用相同方位与滚转，虚线由上端缘至轴向轮廓，没有流向箭头。主图形体未被拆散。

首稿的实际不足：俯视38度时，内芯上端与后侧内缘接近投影相切，可能短暂诱发接触读法；辅助标题的副行距离顶部圆缘过近；数字4偏向内缘，部分字形靠近着色区；Sleeve引线沿轮廓走得太久，归属不如直接进入表面。

一次自修：俯视改48度，方位/滚转、半径和轴向长度均不变；轴向标题上移3mm；数字4左移1.9mm并上移0.2mm；套筒锚点由-93度移至可见外壁-72度，避免贴着轮廓。没有添加阴影、切面、实体或物理含义。图注适度压缩，所有锁定参数保留。

理论依据仅用于解释选择：上缘后方内壁与内芯上端的视图纵向分离量为4 sin(elevation) - 3 cos(elevation)，38度时约0.099原单位，48度约0.965原单位。该式说明投影分离趋势，不代替对最终图的检查，也不证明整幅图优胜。

机器结果：源码连接性、面边界关联与参数核对通过；实际SVG的径向白隙约6mm，对应4原单位。字号9/10.5pt。SVG通用审计为REVIEW_REQUIRED，因为包含位图及复杂背景覆盖，不伪称全图技术PASS。
