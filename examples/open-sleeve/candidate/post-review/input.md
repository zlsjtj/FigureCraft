# 纵向开口套筒与内芯 原创几何演示

套筒与内芯同轴，轴为z。套筒外半径12、内半径9，z从0到30；从套筒中去除全部z范围内的方位角-35°到+35°扇区，形成贯穿壁厚的纵向开口。方位角从+x轴朝+y轴计算。剩余套筒壁是一件连续物体，两端均敞开，不能增加端盖。

内芯是半径5的实心圆柱，z从-3到33。内芯与套筒不接触；在保留套筒壁的角度范围内，两者径向间距为4。没有给定固定件、支承、流动、运动或物理作用，不自行补充。开口是最终物体已有的几何，不是另一次切除操作。
