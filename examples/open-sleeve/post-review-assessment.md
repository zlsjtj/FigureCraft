# 反馈修复后的图形复查

本次是已知初评意见后的模型辅助复查，**不是匿名首稿盲评，也不是独立的新读者实验**。本轮只读取指定的 post-review/figure.png、figure.pdf、caption.txt 和此前 anonymous-figure/B.png；没有读取源码或 DECISION。先看修复图，再重看 B；以下图面记录先于新图注阅读。

## 图面比较记录（尚未读新图注）

- 最明显的变化是删除 B 右侧的 Longitudinal opening 标签及指向深蓝绿色内壁区域的引线。套筒、内芯、上端尺寸线、相机姿态、颜色与遮挡，目视未发现变化；这不是源码或几何模型一致性证明。
- 删除这根引线，消除了“文字把一个有色表面直接命名为空的开口”的局部诱因。此项属于指示关系改善，并不证明深色带本身现在更像空区：深色可见内壁、金色内芯遮挡，以及两者间的投影关系仍与 B 一样。
- 纵向开口仍可由顶部 C 形端缘中断、两侧纵向壁厚面、沿全长露出的内芯、右下方白色缺口共同读出。对知道套筒几何的读者，这些线索足以提示缺失的前壁。
- 图面不再明确命名 Longitudinal opening。初见读者需要自行把这些线索整合为“贯穿壁厚和轴向的开口”，而不能直接完成术语与区域的对应。若对示意图惯例不熟悉，仍可能把它视为展示内部而作的剖视处理；这一问题没有靠删除标签解决。
- Radial gap = 4 及尺寸线、Sleeve、Solid core 均保留，标签归属清楚。未见间隙尺寸或对象辨识明显退步。新图同样没有完整展示下端环口，也不能仅凭投影证明全长、全周保留壁区域均不接触。
- 右侧更空，不代表核心空间关系变得更易理解。构图更安静的收益，与失去目标结构名称的代价必须分别记录。

## 图注、尺寸与综合判断

### 核对结果

新 PDF 为 **160.000 × 95.000 mm**，保留的三项文字均为 **10.5 pt**，与此前 B 的字号水平相同。沒有通过放大页面或缩小文字改变比较条件。这里核对的是 PDF 页面框与有效字号，没有进行实体打印阅读实验。

新图注仍明确给出套筒外/内半径 12/9、内芯半径 5、两者的轴向范围、已有纵向开口的方位角及其贯穿壁厚/全长的性质，也声明连续套筒、两端敞开、不接触、径向间距 4 和任意单位。它能够补足图面不再命名的纵向开口。图注说尺寸线位于套筒上端，这与图面相符；没有发现参数退步或新增物理机制。

不过，图注没有直接解释图中内芯右侧那条深蓝绿色带是透过开口看到的内壁。因此原来的投影解读难点仍在，不能把“删除有歧义的引线”写成“空区与表面已获得清楚的视觉区分”。

### 按关系分别判断

| 关系或目标 | 相比 B 的变化 | 判断 |
|---|---|---|
| 开口引线的对象归属 | 引线及文字被删除，不再把深色内壁作为开口标签的端点。 | 局部改善：消除了一个明确的误导诱因。 |
| 空区与可见表面的视觉区分 | 阴影、颜色、轮廓和遮挡目视未见改变。 | 没有可见改善证据，原来的空间想象负担仍在。 |
| 纵向开口的轮廓/壁厚线索 | C 形顶部、纵向切面和内部露出关系仍在。 | 未见几何线索退步；仍可读出开口，但不是无须背景知识的保证。 |
| 纵向开口的名称和位置对应 | 图内不再出现 Longitudinal opening。 | 语义锚点退步：读者必须从图注把术语映射回图中。 |
| 径向 gap 与数值 4 | 原有文字、尺寸线、上端位置保留。 | 未见退步，也没有新增的间隙证明。 |
| 套筒与实心内芯 | 两个名称和颜色归属保留。 | 未见退步。 |
| 两端敞开与全长不接触 | 下端及部分径向关系仍受遮挡。 | 限制保持；不能称为这次修复解决了这些关系。 |
| 视觉组织 | 右侧少一处文字和跨向物体的引线。 | 局部更安静，但较大留白不是独立的质量提升证据。 |

### 图注现在承担什么

图注不再需要与一个指向表面的开口引线共同工作，因为那根引线已经移除。它现在承担更多**命名与定义开口**的职责，同时继续声明不可见的下端与全长关系。其作用仍以解释和补充为主；没有发现图上明确画错、靠图注强行否认的冲突。与此同时，图注也没有直接解决深色表面与空区如何区分的视觉问题。

## 结论

**结论是“局部改善，语义自足性有所退步；未证明整体优于 B”。** 删除引线减少了指错对象的风险，但没有让开口或间隙的几何更可见。对于已经理解开口套筒的读者，修复图仍可用；对于需要图内直接指认目标结构的初见读者，B 保留名称的优势消失了。

因此不建议仅因文字更少，就把此次修复作为无条件替换 B 的胜出结果。现有证据支持同时保留两者的取舍记录：修复图的指示关系更少出错，B 的目标结构命名更完整。若必须以“图面自足地指认纵向开口”为验收条件，本次修复尚不足以通过；如果图注始终紧邻、读者具备基本几何阅读能力，则可以作为一个有明确代价的备选。
