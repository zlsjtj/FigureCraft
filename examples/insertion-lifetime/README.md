# 同一载片重新插入：一次新材料生成对照

这是原创 DEMO。几何与结果表为预先构造的演示材料，没有做物理实验。原始材料没有告诉执行者贡献主线或构图答案。

同一模型配置、材料、160×100 mm 图幅和一次自主复读机会，分别以普通提示、2.25.4/1.22.4 旧技能及2.25.5/1.22.5候选技能，在三个新上下文生成。没有控制精确 token 或完全相同工具调用次数。`comparison/` 保留三份自主选定稿；它们是独立生成样本，不是同一个脚本换标签。

两名独立模型评审先读匿名产物，不看修改理由；没有真人参与。结果没有全面胜者：旧版开篇更早明确每帧拟合这个已有对照；新版把决定采用价值的 B/D 证据放在前面，随后交代 A/C 反例；普通提示最清楚画出三标记、一次拟合和八输出。新版把同一 ID 与改变后的位姿放在主视觉，代价是逐点数值映射留给正文。三稿都保留13行记录。

`selected/` 是新版经过评后修复的交付，不能当成独立首稿：图注不再否认第二次变换，只说明其数值未提供；补明一个映射服务八孔；去掉没有依据的取景框，把开锁失效与重新闭锁递增分别对应。没有改数据、图幅、字号或几何。见 [评后说明](POSTREVIEW.md)。

这组图适用于比较“什么信息该进入图”，不是所有机制图的模板。若主要任务是教三点仿射，应保留普通提示图的明确数值归属；若主要任务是强调即时失效，旧版中间 Open 状态值得保留。不要因为新版更少面板就一律选新版。

## 重建

Python3，依赖 reportlab、Pillow、numpy、pypdf；另需 Arial 常规/粗体或有相同字形覆盖的替代字体，以及 Poppler pdftoppm。更换字体后需复查排版。源码和 SVG 均可编辑；PDF 为矢量，PNG为300dpi。

```text
python -B -X utf8 source/build.py --inputs inputs --out rebuilt --font PATH/arial.ttf --bold-font PATH/arialbd.ttf --pdftoppm PATH/pdftoppm.exe
```

输出目录必须不存在。命令从这份示例所在目录运行，也可传完整路径；输入和工具位置均由参数指定。源码重建是固定设计重建，不等于再次自主提炼贡献。此次生成没有自然调用 FigureCraft 的关系组件接口，不能据此宣布该接口的自然使用率或迁移能力通过。

## 验证边界

科学数据逐行核对、有限字体/颜色检查、异目录重建、模型辅助理解和视觉评审分别执行。一次新任务不足以证明稳定优于普通提示或旧版；未做真人阅读、印刷、完整色觉覆盖或期刊认可验证。此例在完成对照后才加入技能包，未参与生成本次样本。
