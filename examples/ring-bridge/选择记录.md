# 虚构 DEMO 图文试用

最终选用 `selected/figure.svg`、`figure.pdf`、`figure.png`；英文段落、图注和替代文本在 `selected/text.json`。

读图重点是一件等厚平板如何以三条等宽径向桥连接中央平台和完整外环。全部实际部位共用一种表面颜色；深色只用于同一结构的侧面，不编码第二种材料。空区保留白色贯通窗口。没有添加载荷、变形、运动、测试结果、底座或传感器。

先画同尺寸俯视稿，再画斜视候选进行实际比较。俯视稿容易检查三条桥的均匀间隔，但厚度只能靠文字。斜视稿用连续边界与可见侧壁直接承担“贯通、等厚、一体”的关系，主体在横向版面中也更充分。代价是角度和宽度在投影中不宜直接量取。

保留两个首轮候选：`first_draft`（俯视）和 `oblique_first_draft`（斜视）。仅作一轮自审修复：合并侧壁分片，消除栅格导出细缝；将右侧空区标签外移。没有隐藏首轮问题。

最终尺寸 160×85 mm，标签 9–10 pt，PNG 为 300 dpi。源为 Python 参数化几何，SVG/PDF 全矢量，文字可搜索；字体由外部 Arial 文件提供，不随包复制。独立目录重建的 SVG、PDF、PNG 和 JSON 哈希相同。

实际查看了正常色、灰度与单条件色觉模拟 PNG。SVG 标签脚本保留 REVIEW_REQUIRED：后画 path 的保守遮盖检测不能确定文字对比；实际渲染中标签无遮挡，未将它改写成脚本 PASS。拓扑检查直接读取最终 SVG，得到 1 个连通材料区域、3 个封闭开口。科学与视觉判断均为本代理自审；未取得作者或期刊认可。
