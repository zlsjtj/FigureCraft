# 独立材料试用：先看图的记录

本记录先按 final、first 的顺序查看实际 `figure.png`，在读取输入、评阅问题或图注之前保存。没有读取技能、源码、decision 或自审。本次为模型读图，不是真人试验；不记录阅读时间，不代表作者认可。这里尚不知道规定的精确几何和物理输出尺寸，不以屏幕放大后的细节作为最终字号已合格的证明。

## final：独立看图

- **对象：** 能直接辨认灰色矩形 Base、青色门形 Guard、金色长方体 Insert。门形结构看起来由两个立柱和一根上横梁组成，视觉上连成一个整体。三个标签均有明确对象，Insert 引线指向金色前端面，Guard 指向青色顶部，Base 指向灰色板边。
- **接触：** Guard 两个脚落在 Base 顶面，图上没有可见的脚底分离带，符合“支架站在底板上”的读法。Insert 左右轮廓与 Guard 内缘之间都有可见空隙，上方也有空白，较容易读成不接触 Guard。Insert 下缘投影在 Base 顶面内，单凭这块灰色背景不能严格区分悬空和直接搁置；虽有悬置观感，但没有可核查的底部间隙参照。
- **穿越：** Insert 长轴指向画面右后方，与坐标 y 的方向相容，位于门形开口内。前端面及后端上缘都能看到，但没有立柱对 Insert 的明显遮挡交界。可以读成穿过门框，也可能先看成完整放在门形洞口中；穿越 Guard 前后厚度范围的事实不能仅由“位于开口内”证明。
- **间隙：** 标注 8 的竖直双箭头在开口左上空白区，上端对应横梁下缘，下方延长线接到 Insert 的斜向顶面边缘。比把箭头落在宽阔表面内部更容易追踪。它最自然地被读作上方竖直净空；单位和精确测量位置需要图注。左右都有视觉余量，但没有数量信息；下部空隙尚不自明。
- **视觉取舍：** 视角接近正面，横梁接近水平、两侧立柱较窄，主关系容易分开。三色分对象、少量明暗分表面，形式克制。代价是纵深压缩，Guard 的厚度和 Insert 穿越的前后关系没有很强的遮挡线索。左下坐标轴中 y 方向比 x、z 短得多，方向还能辨认，但比较弱。
- **标签与阅读：** 主要标签较大，归属无需猜测。Insert、Base 的引线从图下方较远处接入，线长但没有交叉；Guard 的引线也未穿过关键间隙。数字 8 比对象名更醒目，突出上方净空，有助于聚焦，但读者可能因此忽略下方尚未表达清楚的间隙。

## first：独立看图

- **对象：** 同样能直接辨认 Base、Guard 和 Insert，标签归属清楚。总体结构与 final 相同，但视角更斜，Base 及 Insert 的纵深更强。
- **接触：** Guard 脚部同样像接在 Base 顶面。金色 Insert 的前部投影压过左柱的内侧范围，后部又被右柱遮住。遮挡可以来自真实前后关系，但快速看图容易把它读成 Insert 贴住或进入立柱；很难仅凭这一视图确认两侧不接触。与 Base 的垂直关系也缺少独立可见间隙参照。
- **穿越：** 后部被右柱遮住、前端伸到左柱前方的投影线索，比 final 更强地提示 Insert 从门框中穿过。与此同时，这正是侧向接触误读的来源。不能把有遮挡直接算作几何碰撞，也不能把遮挡视为侧向净空已经表达清楚。
- **间隙：** 8 的上端对应横梁下缘，下端落在金色顶面的内部。箭头经过白色空间后跨进金色面，数字也邻近金色斜边；它可以表示某一点处的竖直高度，但读者需要推断下端为何落在那个表面位置。没有 final 那样由延长线接到明确边缘的读法。侧向净空受到遮挡，下方净空仍不明。
- **视觉取舍：** 立体感和穿越的前后感较强，坐标 y 方向也较展开。代价是侧面更厚重，右柱压住 Insert 末端，左侧投影关系较紧；关键不接触关系比 final 更难读。更立体并不能抵消这一具体代价。
- **标签与阅读：** 对象名称仍容易找到，三色区分稳定。上方净空标注落在画面中央的多个表面交界附近，增加了端点核对负担；不是标签文字本身太少或太多的问题。

## 暂时比较

从 first 到 final，最清楚的改善是释放 Insert 两侧投影间隙，并把 8 的标注放到更容易追踪的空白区域。代价是纵深和前后穿越线索减弱，坐标 y 也更短。两图均未仅凭图像直接消除 Insert 与 Base 是否接触的疑问。

以上是读取要求之前的观察，尚未判定几何正确性。当前没有旧版、普通条件或其他方法的对照，不能由这两张图判定新版能力胜出。
